Data Beauty Tribe Analytics Competition

Project Overview

This project was undertaken as part of the Data Beauty Tribe Analytics Competition. It involved analysing business data to identify patterns, evaluate performance and generate insights that could support informed business decisions.

My Role and Contributions

I actively participated in the data preparation and analysis stages of the project using Microsoft Excel.

My contributions included:

1. Data Cleaning and Preparation

- Identifying and handling missing values.
- Removing duplicate records.
- Correcting inconsistent data.
- Formatting and organising datasets.
- Sorting and filtering data for analysis.

2. Data Analysis

- Creating PivotTables to summarise and explore data.
- Calculating percentages and performance metrics.
- Comparing business branch performances.
- Analysing product categories.
- Examining profit and loss patterns.
- Identifying unusual trends and inconsistencies.

3. Interpretation of Findings

- Examining analytical results.
- Identifying patterns in business performance.
- Drawing insights from the available data.

Tools Used

- Microsoft Excel
- PivotTables
- Excel filtering and sorting
- Data cleaning techniques
